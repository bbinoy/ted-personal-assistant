# Trip expenses

One job, one pack, one message. Act, never ask what a tool can do.

1. **The trip.** Find its dates, places and bookings in the calendar, the notes and mail ("the trip to Basel, 4 to 5 May"). Do not ask for what they say.
2. **Every cost.** Search mail (2-3 differently phrased queries, the trip's dates, hotels, rail, taxis, meals): receipts and invoices first, attachments opened with `open_file`, then booking confirmations. A booking whose receipt sits on a website (a link, an order page, a "Print receipt" button): open it with `browse` and have the page saved as a PDF, as web-research says. Never tell the person to print, download or forward anything the browser can do.
3. **The pack.** Open every receipt with `open_file` (each mail attachment and each saved page) so it is in the box, and read the amounts from the documents. Keep each receipt as its own PDF (an expense inbox turns each attachment into one line), and name each clearly with the workbench: date, what, amount ("2026-05-04 taxi CHF 24.50.pdf"). A file comes back with an id (file3): get that id from the expert and attach by it, never by a path in the box. Make a short table: date, what, amount, currency, and the total per currency. Never state a figure you did not read.
4. **The draft.** To where the person sends expenses (their notes or an earlier expense mail). If neither has it, in any run (a chat turn or a look): ask the person once, in one short message, for the address (a plain question, not an approval), draft nothing to a guess, and when they answer save it as a note and use it from then on without asking. By default one new mail (there is no thread) carries all the receipt PDFs and the table in the body. If a note about the destination, or the person, says the inbox wants one mail per receipt, draft one mail per receipt instead: that receipt attached, a one-line body (date, what, amount). When the person tells you so, save it like the address. List what is missing ("hotel invoice, asked for at checkout") in the body (the first mail) and in your reply, and add a waiting-on task (`owed_to_me`, person, title) for each, so nothing is lost.
5. **One message.** What is in the pack (every draft, if there are several), the total per currency ("CHF 123.70", counting an amount read from a page even if its PDF is missing), what is missing, then "say send". Show the drafts as the mail skill says. Sending follows the normal approval; one "send" covers all the drafts.
6. **When a step fails** (a file error, a page that will not save): retry once, differently (another file name, a fresh snapshot). Then go on with what works and say in one line what is missing. Never start over, never make a second draft because a part is missing (one mail per receipt aside). A draft you replaced is left alone and not offered again; if the missing item arrives later, update your one draft.
